## Theory behind initial conditions: Galaxy distribution

Citations:
  -  [1]Freeman, K. C., “On the Disks of Spiral and S0 Galaxies”, The Astrophysical Journal, vol. 160, IOP, p. 811, 1970. doi:10.1086/150474.

Most spiral galaxies are made of three main components: A spheroidal 'bulge' at the centre of the galaxy, a surrounding disc, and a large dark matter halo surrounding the galaxy as a whole. For the purposes of this simulation, the dark matter halo has not yet been implemented, so only the first two components will be considered.

Starting with the galactic disk, in almost all measured cases, the luminosity (as a function of the radius) of the disk follows a negative exponential relationship:

$$\mu (R) = \mu_0 e^{- \alpha R}$$

Where $\alpha$ is a constant dictating the scaling relationship.
